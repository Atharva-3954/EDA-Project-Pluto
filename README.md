# Netflix Movies and TV Shows Data Analysis

## Project Overview

In this project, I analyzed the Netflix Movies and TV Shows dataset using Python. The goal was to clean the data, explore different patterns, and create visualizations to understand Netflix content better.

## Dataset Information

**Dataset:** Netflix Movies and TV Shows Dataset

**Source:** Kaggle

**File Used:** `netflix_titles.csv`

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis Performed

* Data Cleaning
* Missing Value Handling
* Duplicate Check
* Exploratory Data Analysis
* Data Visualization
* Insights Generation

## Questions Answered

* Does Netflix have more Movies or TV Shows?
* Which countries produce the most content?
* Which ratings are most common?
* How has Netflix content changed over the years?
* Which genres appear most frequently?

## Visualizations

* Bar Chart
* Line Chart
* Histogram
* Scatter Plot
* Pie Chart
* Heatmap

## Key Findings

* Movies are more common than TV Shows.
* The United States has the highest number of titles.
* TV-MA is one of the most common ratings.
* Netflix content increased rapidly after 2015.
* Some genres appear much more frequently than others.
