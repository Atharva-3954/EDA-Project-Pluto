# 🎬 Netflix Movies and TV Shows - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project was completed as part of the Pluto Academy AI & ML Internship Program.

The main goal of this project is to perform Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset. Through this analysis, I explored the dataset, cleaned the data, created visualizations, and identified useful insights about Netflix content.

This project helped me understand how real-world datasets are analyzed using Python and data visualization techniques.

---

## 🎯 Project Objectives

* Understand the structure of the Netflix dataset.
* Identify and handle missing values and duplicates.
* Perform data cleaning and preprocessing.
* Explore trends and patterns in Netflix content.
* Create meaningful visualizations.
* Generate insights based on the analysis.
* Improve practical skills in data analysis using Python.

---

## 📊 Dataset Information

**Dataset Name:** Netflix Movies and TV Shows Dataset

**Source:** Kaggle

**Dataset Link:**
https://www.kaggle.com/datasets/shivamb/netflix-shows

### Dataset Features

The dataset contains information about Netflix content, including:

* Show ID
* Type (Movie or TV Show)
* Title
* Director
* Cast
* Country
* Date Added
* Release Year
* Rating
* Duration
* Genre
* Description

## 🔄 Project Workflow

### 1️⃣ Data Loading

* Imported required Python libraries.
* Loaded the dataset using Pandas.
* Displayed sample records for understanding the dataset.

### 2️⃣ Data Inspection

* Checked dataset shape.
* Examined column names.
* Reviewed data types.
* Identified missing values.
* Checked duplicate records.

### 3️⃣ Data Cleaning

* Removed duplicate entries.
* Handled missing values.
* Corrected inconsistencies in columns.
* Verified data quality after cleaning.

### 4️⃣ Exploratory Data Analysis (EDA)

Performed analysis using:

* `value_counts()`
* `groupby()`
* `describe()`
* Filtering and aggregation techniques

### 5️⃣ Data Visualization

Created different visualizations to understand content trends and distributions.

### 6️⃣ Insights Generation

Generated observations and findings based on analysis results and visualizations.

## ❓ EDA Questions Answered

The following questions were explored during the analysis:

1. What is the distribution of Movies and TV Shows on Netflix?
2. Which countries contribute the most content to Netflix?
3. What are the most common content ratings on Netflix?
4. Which genres are most frequently available on Netflix?
5. How has Netflix content changed over the years?

## 💡 Key Findings and Insights

* Movies are more common than TV Shows on Netflix.
* The United States contributes the highest amount of content.
* TV-MA is one of the most common content ratings.
* Netflix content has increased significantly over recent years.
* Certain genres appear much more frequently than others.
